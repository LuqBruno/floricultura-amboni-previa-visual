# Floricultura Amboni — prévia visual

Prévia estática e navegável para apresentar a identidade visual e a dinâmica da vitrine.

## O que dá para explorar

- Página inicial e animações visuais
- Categorias e busca do catálogo demonstrativo
- Detalhe do produto e seleção de variações
- Adição e ajuste de itens na sacola de demonstração
- Próxima etapa da jornada, apresentada sem formulário

## O que esta prévia não faz

- Não tem servidor, banco de dados, painel administrativo, login ou conta de cliente
- Não pede nem transmite dados pessoais
- Não registra pedidos, envia mensagens ou cobra pagamentos
- Não mostra catálogo, preço, estoque ou fotos confirmados pela loja

O catálogo estático vem dos exemplos já usados no ambiente de desenvolvimento. Os preços e imagens são ilustrativos e identificados como demonstração. A sacola guarda apenas IDs fictícios e quantidades no armazenamento de sessão desta aba; ela é descartada ao encerrar a sessão do navegador.

## Publicação

O site pode ser publicado como páginas estáticas do GitHub a partir da branch `main`. Não é necessário instalar ou iniciar o servidor do projeto principal.
